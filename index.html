    Where the real work is

    Automation does not fail in the happy path. It fails quietly, weeks later, in a way nobody notices — a report that simply stops updating. Two of mine, and what they cost.

    The copy that was twelve runs behind

    I needed to see why a workflow had failed, so I copied the database file and opened the copy. It showed 729 runs.

    The live database had 741. The twelve missing were the most recent — exactly the ones I was looking for. SQLite keeps recent writes in a separate write-ahead log, and I had copied only the main file.

    Twelve is not a rounding error. It is missing data. Now I open the database read-only, in place.

    Two CDNs, opposite rules

    Every article lost its images. The cause was one word: our download User-Agent contained bot, and one CDN answered 403 to anything that looked automated.

    The obvious fix — send a browser User-Agent — broke the other CDN. That one requires an honest bot User-Agent with contact details, and answers 429 to a generic browser string instead.

    One header cannot satisfy both. The client now picks the User-Agent per host, with a fallback.
